# S.NET Website

Landing page resmi untuk **S.NET**, layanan penyedia internet (ISP) yang menawarkan koneksi super cepat, stabil, dan tanpa batas untuk rumah dan bisnis.

## Fitur Utama

- **Desain Modern & Responsif**: Tampilan menarik dan menyesuaikan dengan berbagai ukuran layar (mobile, tablet, desktop).
- **Informasi Layanan**: Menampilkan keunggulan, paket internet, dan informasi kontak S.NET.
- **Integrasi Portal**: Menyediakan akses cepat ke Portal Pelanggan dan Login Admin (Radius).

## Teknologi yang Digunakan

- HTML5
- CSS3 (Vanilla CSS dengan custom properties/variables)
- JavaScript (Vanilla JS untuk interaktivitas)
- [Google Fonts](https://fonts.google.com/) (Outfit & Inter)
- [Bootstrap Icons](https://icons.getbootstrap.com/)

## Struktur Direktori

```text
.
├── assets/         # Folder untuk gambar dan aset lainnya
├── css/            # Folder untuk stylesheet (style.css)
├── js/             # Folder untuk script interaktif (app.js)
├── index.html      # Halaman utama (Landing Page)
└── README.md       # Dokumentasi proyek
```

## Cara Menjalankan

Proyek ini adalah website statis. Anda cukup membuka file `index.html` di browser web apa pun (seperti Chrome, Firefox, atau Safari) untuk melihatnya, atau letakkan di dalam root direktori web server (seperti Nginx, Apache, dll).
